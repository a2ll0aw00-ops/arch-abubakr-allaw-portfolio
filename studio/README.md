# Studio — إدارة موقع أبوبكر علاو

هذا مصدر Sanity Studio مستقل للتطوير، لكنه مرتبط بالمشروع الحالي نفسه فقط:

- Project ID: `0nta1uyv`
- Dataset: `production`
- لا ينشئ مشروع Sanity جديداً ولا ينسخ البيانات.

## ما تمت إضافته

- Desk structure مرتب حسب صفحات الموقع ومناطق المحتوى.
- مجموعات وحقول واضحة مع وصف يشرح مكان الظهور.
- Presentation Tool لمعاينة مسارات الموقع الحالية.
- حقول `image` وgallery لرفع الصور ومعاينتها وترتيبها.
- حقول الروابط القديمة محفوظة للتوافق ولا تُحذف أو تُعدّل تلقائياً.
- معاينة بصرية للروابط القديمة في السجلات التي ما زالت تستخدمها.

## التشغيل

من مجلد `studio/`:

```bash
npm install
npm run dev
```

للمعاينة المحلية، يشغّل الموقع العام على المنفذ 3000 وStudio على المنفذ الذي يختاره Sanity. يمكن ضبط `SANITY_STUDIO_PREVIEW_URL` إذا كان للموقع عنوان Preview مختلف.

## ملاحظة أمان

هذا المصدر لا يحتوي على Write token داخل الموقع العام. لا يتم نشر أي تغيير إلى dataset إلا من خلال جلسة Sanity Studio المصادق عليها. قبل اعتماد هذه المخططات على Studio الحالي يجب مراجعة توافق الحقول مع المستندات الموجودة، خصوصاً `siteCopy.page` وحقول الصور القديمة.


## إدارة الصور بعد الترحيل

تم تحويل الصور المحلية الحالية إلى أصول Sanity: 28 صورة في 10 سجلات، مع الحفاظ على نفس الملفات والترتيب والمظهر. حقول الروابط القديمة بقيت محفوظة داخلياً للتوافق مع الموقع الحالي لكنها مخفية من واجهة Studio. لإضافة صورة أو تغييرها، افتح المشروع أو الخدمة، انقر على صورة الغلاف أو عنصر المعرض، ثم ارفع صورة جديدة أو اختر Replace؛ لا تحتاج إلى إدخال أي رابط.
